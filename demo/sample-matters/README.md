# Sample matters

Fictional packets for the live demo. Nothing here is a client, a filing, or a real estate.

- **Estate of June Calder.** The task asks for two items. One arrived. The draft should ask only for the other, and it should stay unsent.
- **Estate of Arthur Pell.** The sender has not shown authority. The Bot should stop and should not request documents.

Use `PROMPT.txt` for the words to paste. The skill lives in `skill-waiting-on-the-client.md`.

No Social Security numbers, account numbers, dates of birth, or real street addresses are included. Email addresses are at example.com.
