04 / Hermes

Hermes

  • Dan built his own setup. It is a lot of work.
  • It is a powerful desktop agent. By default it runs on your computer. A cloud computer is one you manage.
  • He kept his own branch. Updates meant resolving conflicts.
  • Sharing skills and connectors across a team took more technical work. A newer portal has improved that. It is still more to maintain than an admin console.
  • Fair reasons to take it on: data control, later prices, open-source models. The maintenance remains.

05 / Grok Bot

Grok Bot

  • Connect an app and sign in.
  • Point it at a skill library.
  • Routines in plain English.
  • A cloud computer.
  • A password vault. The bot does not see the password.
  • It asks before sending.

07 / Admin controls

Admin controls

Business accounts, not a personal login.

  • ChatGPT, in our account: the skills marketplace is connected at the admin level. Skills are packaged into plugins that install for everyone.
  • Grok Bot: a Team Bot shares plugins, secrets, skills, and memory. Each person signs in for their own connectors. Admins set connector policy.
  • Claude business and enterprise plans include admin controls for the organization.

An admin keeps the setup current. Grok Bot is the one Dan uses, because it is easy to use.
