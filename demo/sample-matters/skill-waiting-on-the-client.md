# Skill: waiting-on-the-client

Fictional demo skill. Sample matters only. Do not connect an inbox.

## When to use

An open task is waiting on someone outside the firm, and a new message may already contain part of what was requested.

## Inputs

The open task, the newest message, and the attachment contents. If any of the three is missing, stop and say which one is missing.

## Steps

1. Read the open task and list what it still requires.
2. Read the newest message. Note who sent it and whether the file shows their authority.
3. Read the attachment contents. A filename is not the contents.
4. List only the items that are still missing.
5. If authority or identity is unclear, stop. Do not draft a request.
6. Otherwise prepare a short reply that asks only for the missing items.
7. Return the draft, the three sources, and the statement that the draft is unsent.

## Approval

Do not send email or messages. Do not update a case-management system. Do not mark the task complete.

## Done

The reviewer can see the draft, what arrived, what is still missing, and the sources.
