02 / Math and hard science

Math and hard science

  • October 2026. OpenAI released about 721 manuscripts, in 373 families, from an internal model. Many have Lean formalizations. Not all are checked.
  • Kakeya, claimed in every dimension, was released for review.
  • A challenge to the exponential-time hypothesis is claimed, and under expert review. That review is not a certification.
  • A long quantum Yang-Mills existence proof is held for expert review. The mass gap is not the claim.
  • An earlier Navier-Stokes blowup was claimed. I treat it as claimed. Expert reading has disputed whether the formal proof matches the claim.

06 / Owning your agent systems

Owning your agent systems

  • Most law-firm work does not need a model that can work a Navier-Stokes claim.
  • It needs a harness that gets real work done, organizes the operation, and lets people work together.
  • Own that system. Then you can move when a better tool appears.

09 / Hermes

Hermes

  • I built my own setup. It is a lot of work.
  • It is a powerful desktop agent. By default it runs on your computer. A cloud computer is one you manage.
  • I kept my own branch. Updates meant resolving conflicts.
  • Sharing skills and connectors across a team took more technical work. A newer portal has improved that. It is still more to maintain than an admin console.
  • Fair reasons to take it on: data control, later prices, open-source models. The maintenance remains.

10 / Grok Bot

Grok Bot

  • Connect an app and sign in.
  • Point it at a skill library.
  • Routines in plain English.
  • A cloud computer.
  • A password vault. The bot does not see the password.
  • It asks before sending.

One bot per job

12 / Admin controls

Admin controls

Business accounts, not a personal login.

  • ChatGPT, in our account: the skills marketplace is connected at the admin level. Skills are packaged into plugins that install for everyone.
  • Grok Bot: a Team Bot shares plugins, secrets, skills, and memory. Each person signs in for their own connectors. Admins set connector policy.
  • Claude business and enterprise plans include admin controls for the organization.

An admin keeps the setup current. Grok Bot is the one I use, because it is easy to use.
